**Period:** 2025

> 🏗️ **Project overview**  
> Ediriweera Construction is a construction-industry corporate website designed to introduce the business, communicate its services, showcase completed or featured projects, and make enquiries easier for prospective clients.

## ✨ Website Features

- **Corporate homepage:** a prominent hero, company messaging, and calls to action.
- **About section:** overview of the construction business.
- **Services:** dedicated information about the company's work.
- **Project portfolio:** visual presentation of construction projects.
- **Contact interface:** a customer enquiry form and contact details.
- **Location information:** Google Maps integration for finding the business.
- **Responsive layouts:** presentation adapted for desktop and smaller screens.

## 🧰 Local Setup / Restoration

This is a **WordPress-based project**, not a standalone HTML/React application. The required installation steps depend on what files are actually present in this repository.

To recreate the original website **only if you have an authorized and complete site export**:

1. Prepare a local WordPress environment (such as Local, XAMPP, or an appropriate hosting account).
2. Install WordPress and provision a MySQL/MariaDB database.
3. Restore the original theme, child theme, plugins, media uploads, and database **if those backups are available**.
4. Review site URLs, WordPress permalinks, media references, navigation, and form configuration.
5. Reconfigure integrations and test the restored site on desktop and mobile.

**Important:** Screenshots, a theme folder, or a collection of page assets alone are **not** sufficient to restore a fully working WordPress installation. Do not publish database credentials, admin accounts, API keys, or private client information.
